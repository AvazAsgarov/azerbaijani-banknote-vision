# Utilities (src/utils/)

## Purpose
Reusable cross-cutting helper functions supporting filesystem operations, JSON serialization,
and graphical plot formatting.

## Key Files
- `io.py`: Robust file reading, writing, atomic JSON persistence, and path validation.
- `logging.py`: Structured console and file loggers with consistent timestamps.
- `visualization.py`: Bounding box drawing helpers and standardized image overlay formatters.
