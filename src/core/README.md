# Core Foundation (src/core/)

## Purpose
Provides centralized application configurations, reproducible random seed management,
and canonical dataset constants.

## Key Files
- `config.py`: Dataclasses configuring paths, dataset splits, training parameters, and hardware options.
- `constants.py`: Azerbaijani banknote denomination maps (1, 5, 10, 20, 50, 100, 200 AZN), box colors, and class indices.
