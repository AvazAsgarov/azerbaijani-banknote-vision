# Unit Tests (tests/unit/)

## Purpose
Unit tests verifying component logic, mathematical stability, loss calculations,
and data transformations in isolation.

## Test Areas
- Data processing: deduplication, splitting, schema validation.
- EDA engines: photometric, spatial, manifold, deep dive algorithms.
- TinyML: YOLO-FastestV2 architecture, CIoU loss, quantization, safety guard state machine.
- Dashboard: ETA computation, HTTP request handling, telemetry synchronization.
