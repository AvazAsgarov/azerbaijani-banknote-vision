# TinyML Model Artifacts (artifacts/tinyml/)

## Purpose
Compiled model binaries, quantized headers, convergence figures, and test inferences
generated by the TinyML edge pipeline.

## Contents
- `yolo_fastestv2_int8.tflite`: INT8 quantized FlatBuffer (289.8 KB) with `b'TFL3'` magic header.
- `yolo_fastestv2_int8.h`: C++ byte array header ready for ESP-IDF / Arduino compilation on ESP32-S3.
- `training_metrics.json`: Final convergence metrics, validation losses, and mAP scores.
- `edge_benchmark_results.json`: Microcontroller latency, memory arena, and throughput benchmarks.
