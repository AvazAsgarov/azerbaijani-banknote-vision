# Mobile Constants & Configurations (mobile/src/constants/)

## Purpose
Central repository of theme definitions, currency denomination metadata, and model registries.

## Key Files
- `theme.ts`: AI Academy dark theme palette (#0D0F1A background, #D4F938 neon lime accent, typography, spacing).
- `denominations.ts`: Definitions for all 7 canonical Azerbaijani banknotes (1, 5, 10, 20, 50, 100, 200 AZN), spoken phrases, and risk tiers.
- `models.ts`: Decoupled model architecture registry (YOLOv11m, YOLOv8m, RT-DETR-L, YOLO-FastestV2) supporting dynamic switching.
