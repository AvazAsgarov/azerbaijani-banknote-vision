# Mobile UI Components (mobile/src/components/)

## Purpose
Reusable React Native user interface components designed for high accessibility,
contrast, and visual clarity.

## Components
- `HeaderRibbon.tsx`: Top status bar displaying AI Academy logo, app title, and live wallet balance.
- `BoundingBoxOverlay.tsx`: Real-time bounding box overlay with neon lime corner brackets, denomination badge, and confidence score.
- `TechnicalHUD.tsx`: Expandable diagnostic bar showing FPS, inference latency in ms, active model name, and ESP32 battery/RSSI.
- `QuickControls.tsx`: Accessible large buttons: Torch toggle, Audio mute toggle, Wallet reset, Source toggle.
- `SampleBanknotePicker.tsx`: Horizontal chip selector allowing instant evaluation of any AZN denomination without physical cash.
