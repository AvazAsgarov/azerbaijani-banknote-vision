# Mobile Source Code (mobile/src/)

## Purpose
Root directory for mobile application source code, components, services, constants, and screens.

## Subdirectories
- `components/`: UI components (Header, Bounding Box Overlay, Controls, Technical HUD).
- `services/`: Business logic, audio synthesis, Bluetooth client, frame inference bridge, wallet accumulator.
- `constants/`: Theme definitions, currency denominations, dynamic model registry.
- `screens/`: Application screen containers (CameraVisionScreen).
