# Embedded Firmware (firmware/)

## Purpose
Houses embedded C++ firmware targeted for microcontroller hardware deployment.
Specifically contains firmware for the Seeed Studio XIAO ESP32-S3 Sense smart glasses
assistive vision project.

## Project Structure
- `esp32s3_smart_glasses/`: Complete ESP-IDF C++ project with camera capture, TFLM engine,
  safety guard verification, and audio/BLE notification pipeline.
