# ESP32-S3 Smart Glasses Firmware
**Responsible:** Kazim Mammadli

Runs YOLO-FastestV2 INT8 on Seeed Studio XIAO ESP32-S3 Sense.
- INT8 FlatBuffer: 289.8 KB SRAM, 5.3 FPS at 240 MHz
- 4-tier safety guard, BLE notification channel
- OV2640 sensor, 96x96 YOLO input resolution

Build: Arduino IDE 2.x, Seeed XIAO ESP32-S3 Sense board, 240 MHz, OPI PSRAM enabled.
